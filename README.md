# Ротатор для Panoptix на Arduino  v1.3.4
Программа для управления шаговым двигателем <b>NEMA 23</b> с помощью драйвера <b>TMC2160</b> 
или совместимого. Драйвер подключается по четырехпроводной схеме

**```ENA```** - Enable Разрешает работу мотора  
__```DIR```__ - Direction Направление вращения  
__```CLK```__ - Pulse Тактовые импульсы  
__```GND```__ - Общий

Для корректной работы программы на драйвере должен быть установлен режим 6400 импульсов на оборот. Для **TMC2160**<br>

> - **M0 - OFF**
> - **M1 - ON**
> - **M2 - M4** выставить минимальную силу тока, при котором не будет пропуска шагов
> - **M6** устанавливается ток удержания вала, при **M6 - ON** он составляет 50% от тока вращения.

Для управления шаговым двигателем используется библиотека [GyverStepper](https://github.com/GyverLibs/GyverStepper)<br>
Для приема сигналов от радиопультов используется приемник <b>SYN480R</b> <a href="https://github.com/sui77/rc-switch/tree/master">RC-Switch</a> <br>
За удержание направления отвечает гироскоп-акселерометр BMI160 <a href="https://github.com/hanyazou/BMI160-Arduino?ysclid=m585abcyn8237284085">BMI160-Arduino</a> <br> 
и фильтр Маджвика <a href="https://github.com/robotclass/RobotClass-MadgwickAHRS">MadgwickAHRS</a> <br> 
Показания от гироскопа и акселерометра фильтруются медианным фильтром 3-го порядка <a href="https://github.com/GyverLibs/GyverFilters">GyverFilters</a> <br>
<h2>Что нового</h2>

- Убраны стуки в крайних положениях сканирования
- Изменен алгоритм проверки связи с BMI160 (добавлено принудительное включение режима SPI)
  Если связь с IMU отсутствует, то при включении, светодиод быстро мигет 10 раз
- При нажатии кнопки влево/вправо происходит сначала выход из сканирования
  и только при повторном нажатии непосредственно поворот
- Время опроса приемника вынесено в настройки RX_POLL_INTERVAL
- Уменьшено время игнорирования дребезга контактов
- Уменьшено время реакции на нажатие кнопок
- Если отключен режим Trim, то в ПЗУ вместо трим коэффициентов записываются нули

<h2>Описание работы</h2>

  Управление устройством  осуществляется при помощи двух кнопок двух педалей и потенциометра.<br>
- __```CW```__ вращение с ускорением по часовой стрелке. При нажатии, вал двигателя
начинает вращение по часовой стрелке с ускорением, заданным в настройках до достижении
скорости, установленной потенциометром **```SPEED```** Максимальный угол поворота
при удержании кнопки 360&deg; При нажатии происходит выход из режима сканирования.
По умолчанию ускорение отключено.
- __```CCW```__ вращение с ускорением против чвсовой стрелки. При нажатии, вал двигателя
начинает вращение против часовой стрелки с ускорением заданным в настройках до достижении
скорости, установленной потенциометром __```SPEED```__ Максимальный угол поворота
при удержании кнопки 360&deg; При нажатии происходит выход из режима сканирования.
По умолчанию ускорение отключено.
- __```CW + CCW```__ одновременное нажатие равносильно __```SCAN```__
- __```SCAN```__ запускает режим сканирования. Угол сканирования считывается из ППЗУ.
- __```BRAKE```__ снимает напряжение с мотора, при этом вал свободно вращается.
  При повторном нажатии активирует ___режим Тормоз / Удержание___  
- __```SPEED```__ изменяет скорость вращения мотора.

<h2>Режимы работы</h2>

- __Ручной режим__ при нажатии на педаль происходит вращение мотора в соответствующую сторону. В этом режиме
  скорость вращения можно изменять вращением потенциометра __```SPEED```__. Этот режим активен всегда, совместно
  с любым из других режимов работы
- __Режим сканирования__ для активации этого режима необходимо нажать __```SCAN```__ либо __```CW + CCW```__.
  Вал автоматически поворачивается в пределах сектора, угол которого залан в настройках  
  *Светодиод мигает одной короткой вспышкой*, если выбран угол сканирования #1 (По умолчанию 70&deg;)  
  *Светодиод мигает двумя короткими вспышками*, если выбран угол сканирования #2 (По умолчанию 160&deg;)  
  Переключение между #1 и #2 происходит при долгом нажатии на __```SCAN```__, выбранное значение сохраняется
  в ППЗУ  
  Долгое нажатие подтверждается *быстрыми вспышками светодиода*  
  Центральная точка, относительно которой ведется сканирования формируется при подаче питания
  на устройство и может быть обновлена кратковременным нажатием __```SCAN```__ в режим сканирования.
  Скорость вращения можно регулировать при помощи __```SPEED```__. При выходе из режима сканирования, которое происходит только
  при нажатии на педаль, текущее значение скорости сохраняется в ППЗУ. Если в режиме сканирования потенциометр __```SPEED```__ не менял своего положения,
  то скорость считывается из ППЗУ. При вращении  __```SPEED```__ происходит изменение скорости с последующей записью при выходе из
  режима сканирования.
- __Режим тормоза__ активирует торможение вала двигателя, либо включает режим удержания. В режиме "тормоз" вал двигателя фиксируется.  
  *Светодиод горит ровным светом*  
  Для переключения между режимами тормоза и удержания требуется долгое нажатие на __```BRAKE```__  
  Если режим неактивен, то напряжение на обмотки двигателя не подается, вал свободно вращается, потребление тока минимально.  
  *Светодиод не горит*
- __Режим удержания__ вал двигателя удерживает заданное направление компенсируя вращение корпуса судна вокруг вертикальной оси  
  *Светодиод медленно мигает*

<h2>Программирование пультов</h2>

В память могут быть занесены три двухкнопочных пульта. Алгоритм работы пультов аналогичен работе кнопок.<br>
При одновременном нажатии двух кнопок включается режим сканирования.  

Для **записи** кодов пульта в память контроллера необходимо выполнить следующие действия:<br>
1. Отключить питание <br>
2. Зажать кнопку **`BRAKE`** и подать питание<br>
3. Дождаться пока светодиод начнет мигать. Одна выспышка сигнализирует о готовности к записи кода первой кнопки.<br>
4. Отпустить кнопку **`BRAKE`**<br>
5. Нажать кнопку на пульте, отвечающий за поворот против часовой стрелки<br>
6. Когда светодиод начнет мигать по два раза, нажать вторую кнопку пульта<br>
7. Три вспышки светодиода сообщают о готовности записи кода команды "сканирование". Нажать обе кнопки на пульте одновременно.<br>
8. Пульт готов к работе.<br>
Для записи дополнительных пультов повторить пункты 1-8. Нельзя записать одну кнопку дважды. Автоматический выход из режима программирования происходит через 30 секунд. При записи четвертого пульта, первый стирается
из памяти (FIFO).<br>

Для <b>удаления</b> кодов пультов необходимо:<br>
1. Отключить питание <br>
2. Зажать кнопку **`BRAKE`** и подать питание<br>
3. Дождаться пока светодиод на плате начнет мигать.<br>
4. Продолжать удерживать нажатой кнопку **`BRAKE`** в течение 5 секунд, пока светодиод не загорится постоянным светом.<br>
5. Отпустить кнопку **`BRAKE`** <br>
6. Коды всех пультов удалены из памяти <br>

<h2>Калибровка</h2>

Для уменшения дрейфа и увеличения точности удержания напрвлкния требуется калибровка гироскопа.  
- Установите корпус ротатора так, чтобы плоскость платы датчика BMI160 была параллельна земле
- Температура датчика при калибровке должна быть близкой к температуре, при которой планируется эксплуатация
- В процессе калибровки плата должна быть неподвижна
    
> Для запуска процесса калибровки необходимо:  

 1. Выключить питание устройства
 2. При зажатых кнопках **`BRAKE`** и  __```SCAN```__ подать питание
 3. Когда светодиод начнет быстро мигать, отпустить кнопки **`BRAKE`** и  __```SCAN```__
 4. Светодиод медленно мигнет 10 раз, за это время необходимо обеспечить неподвижность устройства
 5. Светодиод загорится ровным светом - калибровка сенсоров
 6. 5 вспышек светодиода сигнализируют об успешном окончании процесса калибровки

<h2>Настройка</h2>
Для настройки вписываем свои значения в секции настроек после соответствующего #define<br>
Например, для изменения ПЧ редуктора на 4 заменяем<br>

```c++
#define GearRatio 1 // Передаточное число редуктора
```
на

```c++
#define GearRatio 4 // Передаточное число редуктора
```
Текст после двойнойного слэша $\color{grey}{\textsf{// Игнорируется программой}}$

<h2>Установка</h2>

**Способ 1. Установка с использованием Arduino IDE**
- Установить необходимые библиотеки, ссылки на которые имеются в начале описания
- В файле библиотеки BMI160-Arduino BMI160.cpp заменить строчку
  
```c++
#include "BMI160.h"
```
на 
```c++
#include <BMI160Gen.h>
```
 Если датчик BMI160 не подключен в схему, необходимо закомментировать строку
```c++
BMI160.begin(BMI160GenClass::SPI_MODE, /* SS pin# = */10);
```

**Способ 2. Установка с использованием XLoader**
- Установить программу XLoader (Arduino HEX uploader)
- Скачать файл прошивки ABPM8_v1.3.0.hex
- Подключить Arduino к компьютеру с помощью  USB кабеля
- Если драйвера не установились автоматически, то установить драйвер CH340
- В диспетчере устройств определить на каком COM порту определилась наша плата
- Запустить XLoader
- Выбрать
  
  > Hex file - ABPM8_v1.3.0.hex (или другую ревизию)  
  > Device - NANO(ATmega328)  
  > COM port - порт, на котором определилась наша плата  
  > Baud rate - 57600
   
- Нажать Upload  

Процесс прошивки занимает несколько секунд. Если программа долго (больше 1 минуты) не отвечает, то перезапустить XLoader
и изменить значение Baud rate на 115200

> * При прошивке этим способом нет возможности изменять настройки
> * Если датчик BMI160 не подключен в схему, необходимо заливать прошивку ABPM8_v1.3.0_NO_BMI160.hex
